## What it is

A layout methodology with concrete parameters. The core rule: one piece of content, two layout languages that are genuinely different.

## Why

Producing a single version lets you default to whatever you are used to. Producing two forces the question 'what does this content actually want to be'. Choosing before delivery is far cheaper than being told it looks bad.

## Features

- Edition A — newspaper: dense, ruled, multi-column, strong size contrast
- Edition B — Swiss: generous whitespace, strict grid, hierarchy by position
- Shared design tokens: color, spacing, radius
- Post-render visual self-check list

## Quick start

Read `SKILL.md` for both systems' parameters (type scale, line height, column width, whitespace ratios) and the token set.
