## 这是什么

一个排版方法论 + 可执行规范，核心规则只有一条：

**同一份内容，必须出两版，且两版的版式语言要真正不同。**

不是换配色，不是换字体，是两种完全不同的排版逻辑。

## 两版是什么

| 版本 | 版式语言 | 适合 |
|---|---|---|
| **A 报纸版** | 密、有框线、多栏、字号对比强，信息密度高 | 报告、长文、信息图 |
| **B 瑞士版** | 留白大、网格严、无装饰、字号层级靠位置而非大小 | 海报、发布会、品牌物料 |

## 为什么强制两版

只出一版，你会自动滑向「我习惯的那种」；出两版，你被迫回答「这份内容到底适合哪种表达」。

选完再交付，比事后被说「太丑了」便宜得多。

## 内容

```
├── SKILL.md    双版设计规范、共用 token、渲染验证配方
└── LICENSE
```

包含：

- 两套版式系统的具体参数（字号阶梯、行高、栏宽、留白比例）
- 共用设计 token（颜色、间距、圆角）
- 渲染后读图自检清单

## 一条禁令

**不允许两版用同一版式换配色凑数。** 那不算两版。

## 适用场景

海报、长图、HTML 页面、PDF、封面、对比图——任何「做出来给人看」的排版类交付。
